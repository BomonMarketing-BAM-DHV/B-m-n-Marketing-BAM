# Website Bộ môn Marketing – Trường Đại học Hùng Vương TP.HCM

Trang tĩnh chạy trên GitHub Pages.

- `index.html` – giao diện trang
- `data.json` – nội dung (thông tin bộ môn, giảng viên, hoạt động, học phần, liên kết)

Cập nhật nội dung: mở `data.json` trên GitHub → bấm biểu tượng bút chì → sửa → Commit changes. Trang tự cập nhật sau 1–2 phút.
